# 槎山白茶文旅小程序 · UI 重设计出图提示词（豆包 / 即梦）

> 用法：先出「风格母版」定调（只出 1 张，反复抽到满意为止），再用母版做垫图批量出各页面。
> 图片只用来定**风格、布局、配色、质感**；图中的中文一定是糊的，最终文案仍由代码渲染，看稿时请忽略文字内容。

---

## 0. 通用规则（每次都要遵守）

**统一前缀 P0**（每条提示词开头都粘贴这段，保证风格锚定）

```
微信小程序界面设计稿，文旅类手机 App，竖屏 9:19.5，新中式茶文化风格，配色为竹墨绿 #4A7C59、深松绿 #2F5D3A、暖金 #B98E4E、宣纸米白 #F6F2E9、墨色 #20261F，大量留白，细腻高级，卡片式布局，圆角柔和，轻微纸纹质感
```

**统一负面词 N0**

```
文字乱码，复杂中文字，英文标语，水印，logo，多个手机并排展示，3D 立体按钮，霓虹光，紫色调，卡通表情包，粗糙噪点，过曝，脏色，透视畸变，手指畸形
```

**参数建议**

| 用途 | 比例/尺寸 | 备注 |
| --- | --- | --- |
| 页面视觉稿 | 9:19.5（1080×2340） | 对应项目 750rpx 设计稿，1:1 换算 |
| NPC 立绘 | 3:4 竖版 | 半身、纯色或淡墨背景，方便抠图 |
| 景点插画 | 4:3 | 卡片配图 |
| 图标 / 空状态 | 1:1 | 图标建议只用来看风格，落地用 SVG |

**一致性三招**

1. 同一批次里，提示词**前 60 字保持完全一致**（就是 P0），只改中间的画面描述。
2. 用满意的母版做**垫图（参考图）**，权重调到 0.3~0.5，只借风格不借构图。
3. 每页一次出 4 张，只挑 1 张存档；建一个 `style-board` 文件夹攒起来，后面所有稿子都往里对齐。

## 4. 出图之后怎么用

1. **挑 1 张页面母版 + 1 张插画母版** 作为全项目基准，存进 `docs/style-board/`。
2. 把选中的稿子截取 3~5 个关键区域（头图、卡片、按钮、导航栏）作为"色值与圆角取样点"。
3. 我按稿子做两件事：先在 `src/styles/variables.scss` 里对齐色板 / 圆角 / 阴影 token（改一处全站生效），再逐页调布局。**不要让我一次改 19 个页面**——先首页、NPC、研学三页做样板，确认后再铺开。

需要我把某张稿子落成代码时，直接把图片丢进对话，说明要哪一页即可。
